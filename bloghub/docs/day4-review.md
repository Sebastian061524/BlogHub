## Java 与算法

- ArrayList 底层使用数组；LinkedList 底层使用双向链表。
- ArrayList 扩容会分配更大的数组、复制原有元素并替换内部数组引用，ArrayList 对象本身不变。
- ArrayList 按下标访问 O(1)，末尾添加均摊 O(1)，扩容时单次添加 O(n)，中间插入通常因移动元素而为 O(n)。
- LinkedList 按下标访问／插入通常需要 O(n) 定位；已定位节点后，调整相邻连接为 O(1)。不能笼统地说 LinkedList 的所有插入都是 O(1)。
- 文章查询结果主要用于顺序读取和返回客户端，课堂选择 ArrayList 作为合适实现。
- 学习者根据逐级提示编写 `algorithm/mergeTwoArrayList.java`：从后向前合并两个升序数组，使用三个下标选择较大元素，最后补齐 nums2 的剩余元素，避免覆盖 nums1 中尚未读取的数据。
- 算法时间复杂度为 O(m + n)，额外空间 O(1)。学习者在收尾时确认运行结果正确；Codex 使用 JDK 17 编译仓库中的四个算法源文件，并另外执行合并数组 8 项检查，全部通过：课堂四个用例，以及两个空数组、重复值、负数、nums2 全部较大四个场景。
