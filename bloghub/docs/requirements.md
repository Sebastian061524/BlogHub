# BlogHub 需求说明（第 1 周 MVP）

> Day 1 交付：明确业务范围和验收标准，为独立完成数据库与接口设计提供依据。
> 本文不规定数据库表结构、接口路径或实现代码。
> 标注“暂定”的规则由导师补充，可在设计审查时调整。

## 1. 项目目标与范围

开发一个博客后端：用户注册、登录后发布文章，管理自己的文章，并对公开文章发表评论。通过 Postman 或 Apifox 验收，无需开发前端。

本周必须完成：注册登录、身份认证、文章新增／详情／修改／删除、文章分页和分类筛选、分类列表、评论发布与查询、作者权限和基本错误处理。

范围约定：

- 文章发布后直接公开，不设置草稿、审核或私密文章。
- 每篇文章必须且只能属于一个分类；分类由初始化数据预置，本周不提供分类管理功能。
- 评论仅支持单层文本评论，不支持回复、点赞、修改和删除评论。
- 暂不实现作者／标题搜索、管理员后台、文件上传、密码找回。

## 2. 用户身份与权限

| 身份 | 允许的操作 |
| --- | --- |
| 游客（未登录） | 注册、登录、浏览文章列表与详情、查看分类和评论 |
| 已登录用户 | 游客可使用的公开功能，以及发布文章、发表评论 |
| 某篇文章的作者 | 修改和删除该篇文章 |

作者是相对于某篇文章的身份，不是独立的账号角色。同一个用户可以管理自己的文章，也可以阅读和评论他人的文章。

## 3. 功能与业务规则

### 3.1 注册与登录

- 注册需提供用户名和密码；用户名不得重复，重复注册应失败且不产生新账号。
- 注册成功后不自动登录，也不返回登录凭证；用户需再调用登录接口获取凭证。
- 用户名去除首尾空白后使用，区分大小写；注册、登录和唯一性判断必须采用一致规则。例如 Alice 和 alice 是不同用户名，可分别注册，登录时必须使用与注册时一致的大小写。
- 密码使用适合密码存储的单向哈希方式保存，不得明文保存或通过可逆加密存储。
- 密码长度为 6–64 个字符，仅允许英文字母（区分大小写）、数字和英文半角标点符号，即 ASCII U+0021–U+007E 范围内的字符；不强制同时包含这三类字符。
- 密码不允许空格、制表符、换行、中文、全角标点或其他范围外字符；发现非法字符时直接拒绝，不自动删除或替换字符。注册和登录使用一致的输入校验规则。
- 任何响应不得包含密码及密码摘要，登录凭证仅在登录成功时按约定返回，日志不得记录这些敏感信息。
- 登录时校验用户名和密码；成功后获得用于后续身份认证的凭证，失败时统一提示用户名或密码错误。
- 登录接口无需提前携带 JWT。凭证有效期暂定为 2 小时，到期后重新登录；本周不实现刷新令牌或自动续期。
- 缺少、无效或过期的登录凭证均视为未通过身份认证。

### 3.2 文章发布与浏览

- 已登录用户可发布文章，需提供标题、正文和分类。
- 文章作者以当前登录身份为准，调用方不能指定其他用户作为作者。
- 分类必须存在；发布成功后文章立即出现在公开列表中，并可查询详情。
- 文章详情至少包含文章标识、作者公开信息、标题、正文、分类、发布时间和更新时间；评论可单独查询。
- 所有人均可查询文章详情；不存在或已删除的文章返回资源不存在。

### 3.3 文章分页与分类

- 页码从 1 开始，每页固定返回最多 10 条，本周不支持自定义每页数量。
- 暂定省略页码时查询第 1 页；零、负数和非整数页码返回参数错误，不返回第一页数据。
- 文章按发布时间倒序排列；发布时间相同时，按唯一标识倒序排列，保证顺序明确。
- 合法页码超出最后一页时返回空列表；没有文章时同样返回空列表。
- 支持按一个分类筛选；不传分类时查询全部文章。
- 分类参数格式非法时返回参数错误；分类不存在时返回资源不存在；分类存在但没有文章时返回空列表。
- 分页结果包含当前页码、每页数量、符合筛选条件的文章总数和本页文章列表。
- 提供分类列表，至少包含分类标识和名称，供调用方选择。

### 3.4 文章修改与删除

- 只有文章作者可以修改、删除该文章。
- 修改可调整标题、正文和分类，修改后的数据必须符合发布时的校验规则。
- 修改文章不得改变作者和发布时间，成功修改后更新修改时间。
- 删除文章时一并删除所属评论；整次操作应全部成功或全部失败，不得留下部分删除的结果。
- 删除成功后，文章不能再被浏览、修改或评论；再次删除返回资源不存在。

### 3.5 评论发布与查询

- 只有已登录用户可以发表评论；评论发布者以当前登录身份为准。
- 评论只能关联已存在的文章，不能对不存在或已删除的文章发表评论。
- 游客和已登录用户均可查询某篇文章的评论；文章存在但没有评论时返回空列表，文章不存在时返回资源不存在。
- 评论结果至少包含评论标识、评论者公开信息、内容和发布时间。
- 暂定评论按发布时间正序排列，同一时间按唯一标识正序排列；本周评论列表不分页。

## 4. 输入校验

长度均指字符数而非存储字节数；以下数值为允许范围，最大值不是固定长度要求。

| 输入 | 规则 |
| --- | --- |
| 用户名 | 必填，暂定为去除首尾空白后 3–20 个字符，不允许内部空白 |
| 密码 | 必填，6–64 个字符，仅允许英文字母、数字和英文半角标点（ASCII U+0021–U+007E），不允许任何空白字符，不强制混合字符类型 |
| 文章标题 | 必填，1–50 个字符，允许正常空格，不允许全部为空白 |
| 文章正文 | 必填，1–1000 个字符，允许正常空格和换行，不允许全部为空白 |
| 评论内容 | 必填，1–500 个字符，允许正常空格和换行，不允许全部为空白 |
| 文章／分类标识 | 涉及指定资源时必填，必须为正整数，并按业务规则检查资源是否存在 |
| 页码 | 可省略；提供时必须为正整数 |

必填文本不得缺失、为 `null` 或为空字符串；“全部为空白”包括仅由空格、制表符、换行等空白字符构成的输入。

## 5. 错误与安全要求

| 场景 | 业务结果 |
| --- | --- |
| 缺少必填参数、类型错误、长度不符、非法页码 | 参数校验失败，不执行写入 |
| 重复用户名注册 | 注册失败，不新增账号 |
| 用户名或密码错误 | 登录失败，不颁发凭证 |
| 未通过身份认证访问受保护功能 | 拒绝操作，提示需要登录 |
| 已登录用户修改或删除他人文章 | 拒绝操作，提示无操作权限，原数据不变 |
| 文章或分类不存在 | 返回资源不存在，不产生无效关联数据 |
| 系统内部错误 | 返回统一错误，不暴露堆栈、SQL、数据库凭据等内部信息 |

所有接口使用 JSON，成功和失败的返回约定保持一致。JSON 字段、查询参数及路径参数占位符统一采用小驼峰命名（camelCase），与对应 Java DTO／VO 字段同名，例如 userName、categoryName、articleId、pageSize；数据库列名仍按数据库设计使用下划线。具体 HTTP 状态码、业务错误码及响应结构在 `api.md` 中设计。

## 6. 非功能约束

- 使用 Java 17 或 21、Spring Boot、MySQL、MyBatis、JWT 和 Maven。
- 使用单体应用和单个数据库完成业务闭环，本周不引入 Redis、MQ 或分布式架构。
- 提供必要的请求与错误日志，遵守敏感信息不入日志的规则。
- 不设 QPS 或高并发指标，优先保证业务正确、权限可靠、接口可测试。

## 7. 验收场景

- [ ] 合法注册成功；去除首尾空白后完全相同的用户名重复注册失败；Alice 和 alice 可分别注册。
- [ ] 登录时用户名必须匹配注册时的大小写，密码必须正确；用户名或密码不匹配时登录失败。
- [ ] 密码长度为 6 或 64 个字符且字符合法时可通过输入校验；不足 6、超过 64 或包含空白、中文、全角标点时被拒绝，不得删除非法字符后继续处理。
- [ ] 游客可以查看文章、分类和评论，但发布文章和评论时被拒绝。
- [ ] 发布文章后可查到正确作者、标题、正文及分类，不能冒充其他作者。
- [ ] 用户 A 的文章不能被用户 B 修改或删除，拒绝后原数据不变。
- [ ] 分类筛选结果和文章总数一致，文章按约定顺序排列。
- [ ] 页码为 0、负数或非整数时失败；合法页码超出最后一页时返回空列表。
- [ ] 分类存在但无文章、文章存在但无评论时返回空列表。
- [ ] 空值、空字符串、纯空白和超长文本按规则被拒绝。
- [ ] 发布或修改文章时使用不存在的分类会失败。
- [ ] 对不存在或已删除的文章发表评论会失败，评论不能冒充他人发布。
- [ ] 删除文章后，其评论一并删除；删除失败时不留下部分删除的结果。
- [ ] 登录成功响应仅按约定返回登录凭证，不包含密码或密码摘要；其他响应及日志不泄露敏感信息。
- [ ] 登录无需已有 JWT，返回的凭证有效期暂定为 2 小时；过期凭证访问受保护接口被拒绝，用户可重新登录获取新凭证。
