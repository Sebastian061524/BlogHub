## Java 与算法

- String 对象不可变，引用变量可以重新赋值；`concat()` 返回值未接收时，变量仍指向原对象；`+=` 包含赋值。
- 两个引用指向同一个 StringBuilder 时，append 修改对象内容，两者都能观察到变化。
- 编译期常量字符串拼接与普通变量参与的运行时拼接，在对象身份比较上不同；内容比较使用 equals。
- 循环连续拼接时，StringBuilder 可以减少中间字符串与反复复制带来的分配开销；不能简单理解为最终字符串一定占用更多内存。
- 独立编写存在重复元素的 HashSet 解法：遇到已存在元素返回 true；平均时间 O(n)，最坏额外空间 O(n)。
